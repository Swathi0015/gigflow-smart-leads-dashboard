# Smart Leads Dashboard

A full-stack MERN application for managing sales leads with authentication, dashboard access, search, delete, and CSV export features.

---

## Features

- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Lead Management Dashboard
- Search Leads
- Delete Leads
- Export Leads as CSV
- MongoDB Database Integration

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
